Legend of the Red Dragon

RD-001

A side-scrolling platformer presented as a lost Famicom cartridge — Red Dragon Software, Shanghai, 1994, 5,000 units pressed. The fiction is the point, but the engineering is real: there is not a single image file in the project. Every sprite, tile, parallax layer and menu glyph is drawn pixel by pixel in JavaScript at load time, and the whole soundtrack is synthesized through WebAudio.

It runs in a browser with no build step, and ships as a single portable Windows executable that needs nothing installed.

TrophyForge

TF-002

An offline Steam achievement manager. It finds every installed game, reads each one's achievement schema, and unlocks or locks them locally through the Steamworks API — driven from Python over ctypes, with all native calls confined to a worker thread so the interface never blocks on them.

The unlock controls stay disabled unless a game clears every safety check: a modern SDK, a 64-bit build, no VAC, and no online competitive component. When the check itself cannot run, the game is treated as unsupported rather than assumed safe. That boundary is not a setting.
